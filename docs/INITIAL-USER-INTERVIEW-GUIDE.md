# PON 初期ヒアリングガイド（LP理解度・需要検証）

更新日：2026-10-14  
目的：利用者層を狭めず、LPの説明が伝わるか・どの価値が必要とされるかを確認する。結果は仮説の更新に使い、少人数の回答を市場全体の証拠として扱わない。

## 実施ルール

- 1人あたり10〜15分を目安にする。
- 先にサービス説明を口頭で補足しない。まずLPを見てもらう。
- 「便利そうですか？」のような誘導質問を避ける。
- 回答者の氏名・勤務先など、不要な個人情報は記録しない。
- 個人、学生、会社員、事業者、企業、開発・デザイン職、地域活動など、異なる立場から意見を集める。ただし、回答者の属性を理由に参加を排除しない。
- LPが未実装機能を提供していると誤解された場合は、重要な改善課題として記録する。

## 質問の順番

### A. 説明が伝わるか（LPを見た直後）

1. このページは、何をするサービスだと思いましたか？
2. 誰が使うものだと思いましたか？
3. 使うとしたら、最初に何をすると思いますか？
4. どこまでが今使える機能で、どこからが構想・開発中だと理解しましたか？

### B. 自分に関係があるか

5. 自分が最近思いついたこと・困っていることを、ここに入力するとしたら何ですか？（答えたくなければパス可）
6. その発想を今はどのように扱っていますか？ 例：メモする、誰かに話す、調べる、放置する。
7. PONで一番価値がありそうなのはどれですか？ 文章整理／イメージ化／需要確認／費用試算／協力者探し／その他。
8. 逆に、不要・面倒・信用できないと感じた点はどこですか？

### C. 不安・信頼

9. アイデアを入力する前に、何が分かれば安心できますか？
10. 非公開の下書き、匿名表示、公開範囲の選択は、どの程度重要ですか？
11. どんな情報なら公開してよく、どんな情報は絶対に公開したくありませんか？
12. AIが内容を補って整理した場合、どのような表示や編集機能が必要ですか？

### D. 行動と支払意思

13. 今この場で試せるなら、何を入力してみたいですか？
14. どの結果が得られたら、もう一度使うと思いますか？
15. もし無料の基本整理と、追加料金のかかる高品質な可視化があれば、どの条件なら支払う可能性がありますか？ 支払わないという回答も重要です。
16. 友人・同僚に紹介するとしたら、どんな人に、何と言って紹介しますか？

- 回答の確度／補足：

## 集計方法

回答者ごとに、少なくとも以下を分けて数える。

1. **理解**：何のサービスか、何が使えるかを正しく説明できたか。
2. **関心**：具体的な利用場面を自分の言葉で話せたか。
3. **行動意向**：入力したい具体例、再利用の条件を挙げたか。
4. **不安**：公開、権利、AI品質、費用、個人情報、運営への懸念。
5. **支払意思**：具体的な機能・価格・条件に結びついた発言か、単なる「払ってもよい」か。

「いいサービスですね」という社交辞令は、需要の証拠として単独で数えない。クリック、入力、再訪、紹介、実際の支払いなどの行動と区別する。

## 判断の目安（暫定）

- 複数の回答者がサービスの目的を取り違える場合、機能を増やす前にLPの説明を修正する。
- 実装済みだと誤認される場合、開発中表示とCTAを修正する。
- アイデア入力に不安が集中する場合、プライバシー説明と非公開初期設定を優先する。
- 可視化だけに関心が集中する場合も、PON全体の価値が確認できたとは判断しない。整理・検証・次の行動まで必要かを別途確認する。
- 回答が分かれる場合、利用者を切り捨てるのではなく、異なるニーズを支える入口や選択肢を検討する。

## すぐに使う最短版（5問）

1. このサービスは何をするものだと思いましたか？
2. 自分なら何を入力しますか？
3. 使う前に何が不安ですか？
4. どの機能が一番役立ちそうですか？ なぜですか？
5. 今すぐ使えないとしたら、何ができればまた見に来ますか？
