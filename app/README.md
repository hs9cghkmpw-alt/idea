# PON App — Webアプリ試作

このディレクトリは、PONのプロモーションサイトとは分けて管理するWebアプリの試作です。

## 方針
- 最初の提供形態はレスポンシブなWebアプリ
- 将来的なiOS / Androidアプリ化を想定し、UIとサービスロジック・データ層を本実装時に分離する
- Webとモバイルで共通のバックエンド/APIを使える構成を目指す
- アイデア共有を中心に置き、Studioやマッチングは任意の機能として扱う

## 現在の状態
`index.html` は静的な操作確認用プロトタイプです。サンプルデータとブラウザ内の一時状態だけで動作します。

未実装：アカウント、サーバー保存、API、実AI、決済、本人確認、実際のマッチング。

## 将来の推奨構成
- `apps/web`: Web UI
- `apps/mobile`: 将来のiOS / Android UI
- `packages/shared`: 型、バリデーション、共有ルール
- バックエンド/API: 認証、投稿、課金権限、検索、モデレーション

この構成は将来の分割案です。現在は静的プロトタイプのみです。
