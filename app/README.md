# PON App — Webアプリ試作

このディレクトリは、PONのプロモーションサイトとは分けて管理するWebアプリです。プロモーションサイトの公開内容は、このアプリの開発ブランチから変更しません。

## 構成

- `index.html`: 静的なUX確認用プロトタイプ。サンプルデータとブラウザ内状態のみで動作します。
- `mvp/`: Supabase Auth と PostgreSQL RLS を利用する、認証付きWeb MVPの実装開始地点。ローカル設定とDBマイグレーションは `mvp/README.md` を参照してください。
- `PRODUCT-PLAN.md` / `docs/`: プロダクト設計・セキュリティ設計。設計書は実装済みであることや、本番安全性を保証しません。

## 方針

- 最初の提供形態はレスポンシブなWebアプリ
- 将来的なiOS / Androidアプリ化を想定し、APIとドメインルールをクライアントから分離する
- アイデア共有を中心にし、Studio・有料コンテンツ・マッチングは独立した機能として段階導入する
- プロモーションサイトとプロダクトアプリの公開・デプロイを分離する

## MVPの現在地

`mvp/` では、メール認証、アイデアCRUD、下書き、公開範囲2種、RLSポリシーを実装しています。ただし、Supabaseプロジェクトへの接続、DBマイグレーション適用、ビルド、手動セキュリティテストは利用者のテスト環境で実施する必要があります。まだ本番サービスではありません。

未実装：実AI、決済、本人確認、マッチング、通報・モデレーション運用、アカウント削除ワークフロー、監視・復旧体制。
